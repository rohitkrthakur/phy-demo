# ⚛️ Physics Made Simple - Frontend UI

This is a frontend-only project built with **Next.js**, **TypeScript**, and **Tailwind CSS**. It features a clean and responsive layout with a **Navigation Bar**, **Hero Section**, and **Footer**, all designed to present physics content in an accessible and elegant way.

---

## ✨ Features

- ✅ Built with **Next.js App Router**
- ✅ Written in **TypeScript**
- ✅ Styled using **Tailwind CSS**
- ✅ Uses **Montserrat** font from Google Fonts
- ✅ Responsive layout with custom gradients and SVG shapes
- ✅ Fully reusable UI components
- ✅ Dark mode support via system preferences

---

## 🛠️ Technologies Used

- [Next.js](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Google Fonts - Montserrat](https://fonts.google.com/specimen/Montserrat)
